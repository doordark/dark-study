# 农场与小镇性能、自主联网对话修复（2026-11-17）

## 性能改动

- `useFarmResidents` 的半秒模拟快照通过独立订阅交给人物图层，移动位置更新不再触发整个 `FarmScreen` 的 React 状态更新。鸡窝协助直接读取最新快照，继续使用真实位置。
- 人物图层与设置面板分离；设置关闭时不创建面板内容，也不筛选历史。人物按显示字段比较，UI 线程移动期间忽略逻辑位置快照变化，减少重复渲染。
- 人物切换动作移除强制重新挂载的 key，固定帧数组与停顿时间，减少动画重建和重复生命周期订阅。
- 前往小镇时，只预下载当前天色背景、商贩、玩家所需资源。只保留一个预加载 Promise，失败可重试；文件缓存由 Expo 管理。预下载准备文件，不承诺提前完成 GPU 纹理上传。
- 小镇背景加载完成后再挂载角色，随后启动动画和雨效；离开时清理定时器。背景加载失败也能进入可操作状态。
- 原画保留在原目录，`scripts/build-farm-runtime-assets.py` 可重复生成 `assets/images/farm-runtime`。家庭人物缩到每帧 144 像素，商贩缩小到 1152×768，主角步行图按原视口烘焙裁切，去除不可见透明区域。
- 上述五张图的 `宽×高×4` 合计从 **30.00 MiB 降到 13.66 MiB，约减少 54.5%**。这是原始 RGBA 尺寸估算；实际进程、图片缓存和 GPU 占用需设备测量。大屏高密度设备的细节表现仍需实机确认。

## 自主联网对话

- 原来短心情开场可能直接耗尽整段本地计划，在联网概率已命中的情况下仍没有发出 AI 请求；共享话题等较短本地计划也会限制联网段落长度。现在联网命中后先发请求，预留完整段落容量；失败时只播放有文字的本地备选，空占位不会进入对白。
- 打开农场设置/对话记录面板不再暂停居民并取消待返回的 AI 对话。切到小镇、小游戏、房屋、背包和应用后台的暂停行为继续生效。
- 历史区分“AI 请求中”“AI”“本地”，记录联网比例、每日额度、请求间隔、Key、失败、超时或回复校验不通过等具体原因。状态改变会更新历史订阅；恢复旧记录时不恢复过期的请求中状态。
- 联网搜索与 AI 居民对话仍是不同开关。原有联网比例、请求间隔和每日请求额度继续生效；没有修改用户已保存的预算，也没有增加自动重试或绕过额度。
