# NPC 带话与询问任务

2026-11-06。

问题根因：`talk_to` 只携带目标人物，到场后启动通用闲聊；原话题在任务和对话边界丢失。联网续段失败后也会替换成普通本地闲聊。

修复范围：全部六位可行动农场人物共用任务链，不改变集市商人的业务职责。

- `talk_to.purpose` 保存玩家原始委托（最多160字）。本地识别询问、质问、带话、解释与安慰等明确请求；兼容“伟刚/伟纲/唯纲”。代词仅在上一条玩家消息指向唯一人物时解析，不猜测多个人名。
- 对执行前的确认、寻路、目标预约、到场对话与最终报告保留同一目的。普通找人闲聊仍使用原来的自由聊天设置。
- 受托对话以固定的原事开场，使用独立的三轮任务流程，不混入随机兴趣话题。线上提示约束围绕委托；明显丢失主题的批次被拒绝并使用保留目的的本地对白。该检查是轻量话题校验，不是完整的语义推理器。
- “某人骂我”只作为客人转述。先询问情境、原话，不能编造承认、道歉、定罪或和解；完成询问也不等于证明指控。
- 结束后从实际发生的目标人物对白提取答复，反馈到委托者的聊天记录与气泡。途中取消、目标被另一个任务占用或对话中断时报告未完成。报告及委托上下文随对话历史保存，当前玩家询问结果时可引用；不注入无关人物的自主闲聊记忆。
- 没有新增依赖，也没有增加自动联网次数或重试。

检查：`scripts/check-farm-errands.cjs` 覆盖30种人物配对、别名、代词与歧义、引用/否定不触发、目的保留、真实报告、双方取消、超时、本地回退、接受相关线上对白与拒绝明显跑题。已有居民行为回归也通过。没有调用付费AI或运行设备测试。

TypeScript、Expo lint、差异静态检查与最终 Android Hermes 导出通过（`output/farm-v11-android`）。实际模型的自由表达仍需实机确认；未提交或发布。
