## 货币与经营

- 收成进入仓库，不再自动兑换金币。普通与优质库存分开；优质品市价为普通品的 130%，逐件取整。
- 行情按设备现实日期固定为基础价的 85%、100% 或 115%。睡觉只推进农场生长与季节，不刷新行情或订单。
- 每个已解锁品种每天一张采购单，交 2–4 份，报酬为基础总价的 145%（取整）及一份肥料。消耗普通品优先，领过的订单存档后不会再付钱。
- 仓库出售按钮卖出该品种的全部库存。请先留好订单或料理需要的食材。
- 工坊厨房需 Lv.3、280 金币。四种料理消耗食材和加工费，制作后直接出售，不增加第二种货币。按钮显示的收入已扣加工费，食材成本需自行考虑。
- 土壤保水改良三次花费 180 / 420 / 780 金币，要求 Lv.2 / 3 / 4；每级让之后的浇水多保持湿润 15 分钟，最高 75 分钟。
- 原有水壶扩容、抓虫制肥、日常目标、批量收获和浇水继续可用。
- 资金不足以买最便宜种子，且种子、地里作物和仓库全部耗尽时，每现实日可领一次三包萝卜种子。

## 存档

AsyncStorage 键仍为 `dark-study-farm`，结构升级到 `v: 4`。旧存档首次读取时金币重置为 120，田地、种子、累计收获、水壶升级、肥料和农场时间保留；v4 重载保留赚到的金币。新装开局为 120 金币、三包萝卜和两包小麦。

重置发生在安装/加载本次代码后首次打开农场时，代码修改本身不会直接修改手机里尚未打开的存档。

订单、库存、厨房、保水等级和救济日期保存在 `economy`。保存操作串行执行，防止较旧快照覆盖新快照。读取失败时阻止覆盖原存档，保存失败在底部提示。

## 验证

```sh
node scripts/check-farm-economy.cjs
node scripts/check-farm-progress.cjs
npx tsc --noEmit
npx expo lint
```

经济测试覆盖货币一次性迁移、九种作物、连续采收上限、季节产量、品质售价、订单重载防重复与现实跨天、加工材料及费用、坏数据兼容和保水升级。真实手机触摸、布局与存储仍需设备验收。

玩法调研参考：[Farmhand](https://github.com/jeremyckahn/farmhand) 的移动端农场经营定位，以及 [Ticker Farm](https://pakle.itch.io/tickerfarm) 的多种种子、浇水和收获入仓循环。实现为本项目自行编写，未引入这些项目的源代码或资产。
