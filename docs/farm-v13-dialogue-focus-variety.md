# 委托对话聚焦与自主开场变化

2026-11-08，保留已完成的场景、价格和人物面板修改。

这次确认的漏点：带话目的依赖少量关键词，普通“去问某人……”可能被当成无目的聊天；资源动作识别早于带话识别，“问别人几点浇水”会误触发浇水；话题检查只看整段任一匹配，开头提到原事、后面跑题仍可通过。自主话题又偏向固定人物的首个兴趣，开场变化依赖寻路计数。

- 只有明确的纯闲聊邀请才省略委托目的，其余保留原始问题。询问优先于资源动作；目标按请求部分中的姓名位置解析，避免前面提及的人名抢走目标。长问题优先保留实际末尾诉求。
- 委托的每条目标答复都检查具体诉求，去掉单字与通用套话匹配；同时问时间、浇水等内容时不能只回应其中一点。开头提一句相关词后转去聊其他兴趣会被拒绝。线上提示明确每次回答要回应原问题。
- 检查仍属于保守的规则校验，不声称能完整判断任意中文语义。拿不到有效线上答复时，以“现在不方便聊天”结束，反馈尚未得到答案，不再用泛泛的六句本地讨论伪装完成。
- 新增12组日常对话和3组宠物互动（每组3轮）。自主聊天按人物兴趣、当前地点、昼夜加权，并避开同一人物组合最近四次开场；不再用寻路动画序号决定首句。线上提示也提供本轮开场方向及最近的开场避重信息，完全重复的近期线上开头退回本轮新开场。
- 讨论/分歧的话题在双方兴趣与允许分享的主题中轮换，避开最近两次主题；讨论有四种不同起句。小八低落开场增加近期重复限制。
