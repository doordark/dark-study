# Android 桌面大肥鱼（v3 液态玻璃互动升级版）

本次围绕 **互动视觉质感**、**单手灵动交互**、**后台无缝随行** 与 **极致低内存稳定运行** 四个维度，全面重塑 Android 原生悬浮桌宠与应用内设置体验。

## 核心特性

1. **全新三层液态玻璃原生互动架构（告别生硬方框）**
   - **独立悬浮互动卡片（`PetInteractionPanel`）**：双击或长按（也可在设置改为单击直开）大肥鱼时，以大肥鱼锚点为轴心弹簧缩放展开（`OvershootInterpolator` + 透明度渐显 + 微位移），支持 **深海玻璃 / 冰晶浅色 / 跟随系统** 三种液态玻璃主题与分层硬件加速投影，自带指向大肥鱼的平滑曲线指针尾巴，并自动根据屏幕安全区计算上方/下方展开方向与水平边界，**永不出屏截断**；点击面板外（`FLAG_WATCH_OUTSIDE_TOUCH`）、关闭按钮、拖动桌宠或 22 秒无操作自动丝滑收起。
   - **互动卡片功能丰富顺手**：
     - 头部复用已缓存 `idle` 图集裁剪的圆形大肥鱼头像徽章（**零额外 Bitmap 内存**）、动态情绪胶囊以及实时刷新反馈的 **饱食 / 心情 / 好感** 三项微进度条；
     - 面板内集成轻声回应条（互动结果不与面板重叠遮挡）与 **下节课倒计时动态胶囊**（点击直达 `dark-study://` 课表）；
     - 2×3 液态玻璃操作格：**喂团子 / 摸摸头 / 换动作（跳舞·转圈·学习·探头·打盹循环）/ 查课表 / 去聊天 / 贴边安静休息**；
     - **快速聊两句** 零延迟本地人设回应胶囊（`夸夸我` / `下节课?` / `陪我学`）与底部 **防误触穿透 / 收回桌宠** 快捷栏。
   - **独立贴边自适应气泡（`PetBubbleWindow`）**：非阻断触控（`FLAG_NOT_TOUCHABLE`），按文本长度自适应宽高（最宽 248dp），带平滑曲线尾巴与情绪色点、弹簧弹出淡出动画、顶部空间不足自动翻转至桌宠下方，彻底告别旧版 148dp 窄框截断。
   - **贴边安静休息模式（Edge-Rest）**：一键让大肥鱼自动滑到最近屏幕边缘贴边探头休息（柔和降透明 + 低频 12fps + 轻巧月亮徽章），不挡游戏或阅读，轻点即可元气唤醒；通知栏同样支持一键切换「贴边休 / 唤醒」「防误触」「收回」。

2. **切后台自动随行桌面（0ms 无缝接力）**
   - 在软件内叫出桌宠并开启「切后台自动出现在桌面」后，前台预驻留零绘制 Standby 待命服务（View `GONE`，12 秒后彻底释放全部 Bitmap），规避 Android 12–15 后台启动前台服务限制。
   - 切到桌面或其他应用时，原生悬浮窗按当前坐标、朝向、体型倍率、透明度、玻璃主题、手势偏好与下节课倒计时无缝接力显现；切回应用后自动隐藏并全量同步喂饭、摸头、戳戳与撞边记录。

3. **严格低内存与生命周期防泄漏**
   - `SheetBank` 坚持 **2 槽位按需异步解码**（仅驻留 `idle` + 当前 1 张动作图集），低密度屏（`density < 2.15`）或低内存设备（`ActivityManager.isLowRamDevice`）自动 `inSampleSize = 2`（节省 75% RAM），解码捕获 `OutOfMemoryError` 自动降级重试，且在后台线程与 `handler.post` 失败分支均确保释放已解码 Bitmap，杜绝关闭竞态泄漏。
   - 所有 `ValueAnimator`、`Handler` 回调、`Choreographer` 帧回调、`VelocityTracker` 及三层 `WindowManager` 视图（本体 / 气泡 / 互动卡片）均在 `onDestroy`、`dismiss`、`setStandbyHidden(true)` 与息屏时彻底取消、移除并做好重复 `addView` / 非附着 `removeView` 防护。

4. **应用内可视化设置页（`DesktopPetSettings.tsx`）**
   - 与 Dark Study 液态玻璃视觉统一：顶部提供实时交互预览舞台（实时反映体型 85%/100%/120%、透明度 65%/82%/100%、玻璃主题与气泡开关，可直接试玩喂团子/摸头/跳舞/探头动作），下方清晰分组展示外观质感、单击手势偏好、自主气泡开关、手势速查与分厂商权限/后台保活引导。

## 重新构建提醒

修改了原生 Kotlin（`plugins/whale-overlay/WhaleOverlay.kt`）与 Expo 配置插件（`plugins/withWhaleOverlay.js`），旧 APK、Expo Go 和纯 JS 热更新不包含新原生界面。请在集成构建阶段同步生成 `android/` 并重新打包安装 APK：

```powershell
npx expo prebuild --platform android --no-install
npx expo run:android
```
