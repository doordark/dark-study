## 本次修复

| 范围 | 问题与结果 |
| --- | --- |
| 在线更新 | 取消后立即重下，旧请求的进度、成功或失败可能覆盖新任务，甚至清除新任务取消句柄。改为按请求代次隔离。 |
| 安装包下载 | 建目录期间取消不能阻止下载；HTTP 错误或空文件可能被当成成功。现在检查取消、HTTP 200、非空文件，每次下载独立文件，失败清理残留，清除过期下载缓存。 |
| AI 改课 | 确认旧消息时如果已切换课表，操作会落入新课表。现在阻止跨课表旧操作；批量操作逐条读取最新状态，支持先新建再加课、改名后再定位删除；阻止模型修改课程 ID。 |
| AI 网络故障 | 内层 3 次重试结束后，外层 JSON 重试仍会继续，累计最多 9 次。现在网络错误最多 3 次，保留 HTTP 400 的 JSON 兼容降级及解析重试。 |
| 成绩导入 | 空白绩点被 Number 转为 0，覆盖按分数推算的绩点。现在空值按缺失处理，明确填写的 0 保留。 |
| 存储迁移 | 删除新键后，下次读取会回退到旧键，导致旧数据复活。现在删除时同时清除对应旧键。 |
| 页面耗电 | 课表、农场、小组件预览计时器在隐藏页面或后台仍运行。统一为只在页面聚焦且前台时轮询，恢复时立即刷新。课表当前日期信息随时钟更新。 |
| 课程提醒 | 增加编辑防抖、仅订阅当前课表、跳过已过期同步任务；约束提醒参数，避免一分钟内重复提醒；权限读取失败不会产生未处理拒绝，Android 专属查询不在 iOS 执行。 |
| 代码精简 | 相机选图复用已有图片转换函数，减少重复实现；生成产物 output/ 排除出 Git。 |
| 重建一致性 | 发布配置插件明确保留 R8 压缩开关，确保资源裁剪与代码压缩在 prebuild 后一起启用。 |

## 验证边界与真机重点

没有连接 Android 设备，未跑界面交互、耗电实测、完整 Gradle APK 构建或安装测试。不能保证不存在其他 bug。下面行为需要新 APK 在手机上确认：

1. 桌宠授权后切 Home、拖动撞边、熄屏唤醒、通知栏收回。
2. 开启提醒、快速修改提前量或切换课表、关闭提醒后检查系统待提醒是否正确。
3. 添加桌面小组件，切换课表后内容是否跟随更新。
4. 更新下载中取消后立即重下，确认进度和取消操作不串任务。
5. 在农场或星空切后台再返回，确认画面、时间和状态继续正常。

打包前仍需应用已有原生插件：`npx expo prebuild --platform android --no-install`。本次未修改版本号，也未自动发布。
