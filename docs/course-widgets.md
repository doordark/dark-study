# 桌面课表小组件（Android）

设置 → 桌面课表小组件，选择正方形（2×2）、长方形（4×2）、大卡片（4×4），点击添加。也可长按桌面，在 Dark Study 的小组件列表中添加任意款式。实际格数由桌面启动器决定，三种组件均支持拖动调整尺寸。

显示当前课表正在上和接下来的课程，包含课程名、日期、起止时间和教室。右上角显示当前日期、教学周和星期（如 `11.4 第8周 周三`），小尺寸只显示日期和星期。课程左侧色条、小圆点与行底色跟随课表里为课程设置的主题色。自动按实际教学周排序、跳过已经结束的课，在无课程/学期结束时显示空状态。设置中最多显示 1–5 门课；小尺寸通常容纳 1–2 门，大卡片最多 5 门。剩余高度会按可见课程数均分并等比放大字号，避免组件底部留白。数量、深浅模式和主题色应用到所有已添加的组件；样式选择决定下一次添加哪一种，不会替换现有组件。

点击组件打开课表，点击顶部 DARK STUDY ↻ 手动刷新。修改、导入、切换课表或再次打开应用时，等待存储恢复后将当前课表同步到安卓独立存储。原生端保留完整学期数据，因此应用进程关闭后仍能重新计算教学周；启动器每 30 分钟刷新一次，并在课程起止时安排无精确闹钟权限要求的刷新。重启、系统时间/时区修改和应用升级也会重新计算。系统休眠、省电和强行停止应用会影响刷新时机。

原生代码源文件为 `plugins/course-widget/CourseWidget.kt`，由 `plugins/withCourseWidgets.js` 在 Expo prebuild 时生成接收器、布局和桥接注册。不要直接修改被忽略的 `android/` 目录。无新第三方依赖。iOS/Web 可查看设置预览，桌面组件当前仅实现 Android。

必须安装重新构建的原生应用；旧 APK、Expo Go 或仅 OTA 更新不会新增安卓组件。

验证命令：

```sh
node scripts/check-course-widgets.cjs
npx tsc --noEmit
npm run lint
npx expo prebuild --platform android --no-install
```

设备验收：分别添加三种样式；编辑课程、切换课表并回桌面；改变数量、配色；拉伸组件检查可见行数；结束应用进程后跨课程结束时间检查自动换课；检查重启、无课、学期结束、周次跳跃、点击返回课表和启动器不支持固定组件的手动添加提示。

## 澎湃 OS 添加诊断

设置页显示 Android AppWidgetManager 实际注册数、绑定实例数；添加请求被接受不等于已添加，应用通过绑定实例数变化确认结果。八秒未确认时显示说明，不报告成功；稍后返回应用会再次刷新数量。旧原生包不支持诊断 API 时提示安装完整新版 APK。

权限入口优先打开小米应用权限管理，无法打开时回退到 Android 应用详情页。是否有「桌面快捷方式」权限以及安卓组件列表入口，取决于 ROM 版本。为不使用 previewLayout 的启动器补充 previewImage。

参考：https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1584 。小米商店详情页展示经过审核的组件，本应用当前是标准 Android Widget，不添加未经完整适配及审核的 miuiWidget 标识。此改动解决静默请求及诊断缺失，不代表已完成澎湃 OS 4 真机验证。
