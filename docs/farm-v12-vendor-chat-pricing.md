# 集市聊天失败处理与真实议价

2026-11-06，接续已有 NPC 行为任务，不覆盖场景与贴图成果。

## 确认的原因

- 集市发送函数预先赋值固定招呼。无 Key、请求报错、返回 JSON 合法但不符合人物回复结构时，没有替换这个初值，造成无关台词。
- 集市请求没有启用已有的玩家主动聊天重试与 JSON 降级；农场个人聊天已有短重试。
- 提示词禁止商人改价，结构也只允许 `action:null`，聊天和真实价格没有连接。

## 调整

- 集市聊天抽出独立服务，保留最近与相关上下文，提供真实在售种子/道具报价，不再用固定招呼补失败。
- 玩家主动聊天最多两次额外尝试，沿用26秒总时限；503等临时故障可短重试，JSON语法或人物回复结构错误共用同一重试预算，降级普通模式要求输出严格 JSON。401/403/余额不足不会盲目重试。自动 NPC 对话默认单请求规则不变。
- 最终失败或无法联网统一显示“现在不方便聊天，稍后再来找我吧。”。失败轮次保留在可见聊天记录，但不增加好感、不改变情绪、不进入后续模型上下文或家人话题分享。旧招呼回复也从商人的模型上下文中排除。
- 错误诊断仅记录固定原因、HTTP状态与是否可重试/格式失败，不打印 Key、聊天原文或服务端正文。没有实机日志，不能将某次手机故障归因为特定网络或账户错误。
- 商人可输出 `set_discount`，只能请求0～100的有限数值，实际执行会按商人性格、好感和心情限额到0～15%。不悦不议价且仍加价，生气拒售；折扣不累加，全部优惠合计最多25%。
- 议价结果保存于装备存档中的 `priceDeals`，到下一次整点商品刷新到期。旧存档默认无协议。价格计算、显示与购买扣款共用同一协议及报价函数。响应里改价的文字由实际执行结果替换，避免只口头答应。
- 商人不获取任意改金币、奖励、库存或自动成交的权限。普通改价只影响本店本轮报价；玩家仍自行购买。

## 验证

`check-vendor-chat.cjs` 使用模拟HTTP覆盖上下文、报价信息、503恢复、鉴权错误、回复结构降级、最终失败、搜索失败、真实折扣与上限/到期/存档、负面情绪限制和失败不刷好感。已有聊天传输、商人情绪与居民行为检查通过。没有调用真实账户或付费API；手机实际网络与模型回复需实机验收。

TypeScript、Expo lint、差异静态检查与 Android Hermes 导出均通过，最终产物在 `output/farm-v12-android`。未提交或发布。
