# 人物面板与作物裁剪修补

2026-11-06。

- 农场居民与四位集市商人统一使用 `FarmNPCSheet` 底部面板。短内容自然收拢，长内容限高滚动；对话没有历史时显示简短招呼，不再用空的全屏列表占据整页。
- 共享面板读取键盘顶部的屏幕位置，同时测量 Modal 实际边界，处理覆盖式键盘和系统 adjustResize；不再由两层 KeyboardAvoidingView/安全距离分别抬升。输入区保留在滚动内容外，身体区域可收缩。
- 姓名、情绪、好感度统一放在标题行，窄屏允许换行。集市分类改为完整换行按钮，避免横向滚动时出现半截按钮；去掉重复的情绪行与农场旧拖动条。
- 作物图集的九行实际位置并不等分。旧版按九等分读取，导致部分作物顶部截断、底部露出下一行。现在为全部36个生长状态测量 alpha 像素边界，记录在 `cropFrames.ts`，每格独立裁剪、等比缩放并底部居中；不重绘原有素材。
- 十二种成熟作物裁剪预览：`output/crop-trim-preview.png`。已直接检查图片，未见相邻作物碎片。

TypeScript、Expo lint、Git whitespace 和 Android Hermes 导出检查通过，产物在 `output/farm-v8-android`。本次未修改原生依赖，也未安装设备或实测具体输入法。
