## 必要检查

浏览器移动修补：React Native Web 的 Pressable 点击回调传入原始 MouseEvent，不含原生触摸的 locationX/locationY；旧代码将 undefined 除以缩放比例，产生 NaN，进而导致玩家消失或不移动。新增 `farmPressPoint` 共用转换器，原生使用局部坐标，浏览器用 client 坐标减当前场景点击层的 bounding rect（兼容滚动）。农场和集市均接入；移动入口拒绝非有限目标，并可恢复此前已被 NaN 污染的玩家位置。`scripts/check-farm-input.cjs` 定向覆盖手机触摸、浏览器鼠标、滚动场景、原点及无效坐标；该定向回归与类型、lint、构建检查均通过。

玩家与出口修补：玩家静止时只使用稳定待机帧，步行动画最低间隔85ms；图集按人物和动作重新挂载，避免6列/8列图集切换时短暂沿用旧帧编号。农场出口从固定92像素的小热区改为底部30个逻辑单位的完整入口区域，地面点击底部也进入同一流程；先走到新地图门口(85,316)，再切换集市。集市返回出口同步扩大，离开农场后停止隐藏玩家动画。静态检查与资源构建通过，实际设备显示仍待用户验收。

背包格子追加：`assets/images/farm-bag-slots-v6.png`，2172×724，6列2行，12种状态；空格皮革、普通银白、稀有蓝、史诗紫、传说金与珍藏珠光白，第二行为对应选中态。使用同一背包装备图作 imagegen 参考，提示为「production inventory slot background atlas, exact six columns two rows, square cells, stitched leather/parchment, metallic corner clasps, five rarity styles, selected sage-green corner clasps; quiet light centers, no items, icons or text」。已接入背包四列等比格子，尺寸随面板实际宽度计算；替换原纯色方块、CSS边框和珠光渐变层。物品图标与文字缩放以留在内框中。
