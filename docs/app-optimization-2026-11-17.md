# Dark Study 本轮优化与验证

## 已实现的六项工作

| 项目 | 行为与范围 |
| --- | --- |
| 聊天列表 | 助手消息使用倒序数据与反向 FlatList，只挂载附近消息；单条消息独立记忆化。保留图片预览、来源、课程操作与长按多选。阅读历史时按当前位置决定是否跟随最新消息。 |
| 农场存档 | 500 毫秒合并连续变化，一次正在写入、一个最新待写快照，真正写入时才序列化；失败保留待写数据。切后台、卸载或导出备份前补存。预算预留继续立即持久化。 |
| 页面更新范围 | 作物、水润状态与虫害按钮移到 FarmCropLayer，独立每 3 秒刷新；主页面时钟改为每 30 秒更新。金币、背包、播种等操作仍立即更新。隐藏小镇后的农场作物停表，返回时重新对时。 |
| AI 请求 | 公共队列最多并发两项，后台闲聊最多一项，排队时主动操作优先。助手有“停止生成”，离开页面、切后台或遗忘记忆时取消请求；搜索及回答沿用取消信号。排队取消不会预留居民每日额度；实际请求开始前才预留并落盘。 |
| 备份恢复 | 设置 → 备份与恢复，可导出 JSON，选择文件后校验并预览数量，再选择合并或覆盖。写入前记录原数据日志，失败回滚，启动时恢复中断的事务；成功后重挂本地场景。 |
| 画质与测量 | 设置 → 性能与诊断，提供流畅／标准／精美三档，控制雨效、装饰数量、待机动画及玻璃模糊。系统减少动态效果优先。显示最多 20 条本次启动的请求耗时记录，不记录消息正文。提供 Android 帧统计、内存及启动时间采集脚本。 |

流畅档保留走动、对话和游戏逻辑，关闭装饰、雨效、待机动画与模糊。标准档保留适量装饰，精美档显示完整装饰。装饰在页面隐藏或应用切后台时停止动画。

## 备份规则

- 包括课表、成绩、农场进度、居民设置与记录、大肥鱼聊天与事实记忆、人设、桌宠养护、小组件偏好及语音开关。
- API 密钥、联网用量、本地背景/缓存图片文件不进入备份。覆盖恢复保留当前设备的 API 密钥与自定义背景；远程图片链接可以保留。旧聊天中的待应用课程操作不恢复。
- 合并追加不同 ID 的课表、成绩和记忆；相同 ID 保留当前内容。已有农场、偏好与居民设置保留当前值，避免累加金币和库存。聊天仍受每组 200 条、事实记忆 60 条的上限约束，当前记录优先保留。
- 当前备份外层版本为 1，课表存储版本为 6；不接受未来版本或损坏的结构。文件大小上限为 20 MB。
- Android 通过系统目录选择器保存；网页下载 JSON；iOS 打开文件分享面板。未新增原生依赖。
- 恢复时暂停 AI 请求并补存农场；后台正在识别课表或成绩时，需等分析完成后恢复。恢复不修改当前联网用量。

## 自动检查

```powershell
npm run check:optimization
npx tsc --noEmit
npm run lint
```

`check:optimization` 汇总 13 项检查，覆盖：合并写入顺序、失败重试、AI 并发与优先级、排队/执行中取消、队列暂停、预算落盘失败阻止 HTTP、排队取消不占额度、真实 Zustand Store 恢复、即时偏好导出、密钥与用量排除、错误文件拒绝、部分写入回滚和中断恢复，以及原有对话、人物、委托、动画、地图、课程编辑与导入回归。

13 项检查通过；TypeScript、lint 及 Android Metro/Hermes 导出通过。导出校验使用工作区内临时目录，不修改系统 TEMP/TMP；未生成 APK。网络测试使用模拟传输，没有调用付费模型。

## Android 真机采集

本机存在 adb，但执行 `adb devices -l` 时设备列表为空，故本轮没有真实帧率、内存或启动时间结果。

安装包含本轮修改的正式构建，并在同一设备上分别保存修改前后构建的记录。手动选择对应画质后，执行：

```powershell
.\scripts\capture-android-performance.ps1 -Scenario farm-town -Phase after -Quality standard -Seconds 30
.\scripts\capture-android-performance.ps1 -Scenario long-chat -Phase after -Quality standard -Seconds 30
.\scripts\capture-android-performance.ps1 -Scenario cold-start -Phase after -Quality standard -Seconds 15
```

多设备时使用 `-Serial`；adb 不在默认 SDK 路径时使用 `-Adb`。结果默认保存在 `.tmp-performance` 下的独立时间目录，含设备/版本信息、原始 gfxinfo、framestats、前后 meminfo、窗口状态和 `summary.json`。缺失数据写为 null；没有有效帧时不生成“零掉帧”的结论。采集脚本已检查语法和摘要解析，未执行无设备的模拟测量。

每个场景至少重复三次，保持设备刷新率、画质、数据量与网络条件一致：

1. 农场 → 小镇 → 农场连续往返，回到稳定画面后看 PSS 是否持续增长。
2. 使用专门的测试聊天记录，检查 200 条消息的滚动、图片预览、多选、阅读旧消息时接收新回复、停止生成后立即发下一条。
3. 冷启动记录 `am start -W` 的 TotalTime；这个数值表示 Android Activity 启动耗时，不能等同于整个 JS 页面可交互时间。

## 尚待界面与设备验证

- 没有 Browser 插件，也没有已安装的 Playwright；尝试现有浏览器工具验证本地页面。内置浏览器初始化出现 Statsig 超时；Edge 访问 localhost 与 127.0.0.1 的 8091 端口均连接超时。未取得页面截图或交互通过证据，测试开发服务已停止。
- 因此，备份文件选择器、Android 保存目录、iOS 分享、长聊天列表视觉布局、停止按钮、画质切换仍需设备或可连接浏览器验收。
- 真实模型对话成功率、第一次进入小镇的掉帧与进程峰值内存均未实测。此处不将自动检查或打包成功当作真机性能结果。
