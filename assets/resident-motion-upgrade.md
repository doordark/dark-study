全部新素材使用内置 imagegen 生成/编辑，再复制到本项目；未使用付费模型接口生成居民测试对白。原有角色作为参考，保留蓝发女仆的鲸鱼装饰、衣服和比例。

透明图集的格子按行读取。帧播放器在 UI 线程更新偏移，不通过每帧 React 更新驱动；后台及系统减少动态效果时停止逐帧动画。农场居民位置使用连续位移动画；跨区沿菜地下方草地行走。点击人物时读取其当前坐标，玩家会向实际位置走近。

## 居民生活

农场底部“居民生活”可设置散步、互聊、45/90/180 秒间隔、联网开关，查看最近 40 句记录。六位居民的人设保存在 `src/utils/farmLife.ts`，本地对白十组，每轮两句，不持续接龙。

默认开启本地互聊，联网关闭，因此默认不消耗模型 token。联网需已有 API Key，并明确开启：默认最短 10 分钟、每日最多 3 次，可改为 5/10/20 分钟及 1/3/5 次；单次只携带两位角色的短人设和昼夜环境，不发送历史，最多 220 输出 token，另计固定短提示输入。失败或取消也占次数；失败、格式不合规、冷却或超额会使用本地对白，不自动重试。每日计数按设备实际日期，不使用农场游戏日期。先保存用量预留，再请求；记录读取或保存失败会暂停联网。

离开农场、切后台、打开操作面板或主动与人物聊天会取消当前互聊和请求。反复开关面板仍须遵守上一轮的间隔。

## 最终生成提示摘要

- 跳舞：以原蓝发鲸鱼女仆为参考，4×2 等格，全身同大小、脚底对齐，八个连续跳舞姿态，手臂与裙摆自然摆动，无字、无网格、透明背景。随后用 imagegen 去除空白区域底色并保留角色。
- 转圈：同一角色与服装，4×2 八朝向序列，正面、前侧、侧面、后侧、背面、另一后侧、另一侧面、回到前侧，保持中心、比例与落脚点；空白处真实透明。
- 日常动作：4×4，每行分别是招呼、进食、学习、入睡的四个连续姿态；表情、眼睛和道具有可见变化，完整角色、等格、透明。
- 头像：同一角色近景，2×2，睁眼、半闭、闭眼、俏皮眨眼，保留鲸鱼饰物，适合小尺寸圆形按钮，透明。
- 居民：温暖像素农场风格，4 列 7 行；每行固定同一人物，待机、迈左步、迈右步、说话手势。依次为 door、顾、小八、玉洁、唯纲、小鸡坤坤、草帽玩家；等格、透明、无字。
- 地图：以原农场白天地图为编辑目标，丰富草地层次、房屋、花草、田边和池塘贴图，保留原土地及池塘交互布局；再以新白天地图生成完全对齐的夜景，冷月色、暖窗灯、柔和夜间细节。

## 验证

纯逻辑检查：`node scripts/check-farm-life.cjs`。模拟请求检查：`node scripts/check-life-chat-client.cjs`，验证输出额度、取消、超时及不重试，不访问真实 API。另执行项目 lint、TypeScript 检查及 Web 导出。尚需 Android/iOS 真机确认小屏气泡遮挡、长时间动画流畅度和操作手感。

接口参数参考：[DeepSeek Chat Completion](https://api-docs.deepseek.com/api/create-chat-completion)。
